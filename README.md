## About the book

*From Competition Problems to Mathematical Proof* is a free 637-page competition mathematics textbook designed to bridge advanced AMC/AIME problem solving and introductory proof-based olympiad mathematics.

The book covers:

- number theory
- algebra and inequalities
- combinatorics and graph theory
- Euclidean and coordinate geometry
- functional equations
- proof strategy and mathematical writing

Each chapter includes motivating problems, core theory, technique-recognition guidance, worked examples, solution-discovery commentary, common mistakes, graded practice problems, hints, and complete solutions.

## AxiomTrace

The book introduces **AxiomTrace**, a structured proof-auditing framework that helps students examine:

- assumptions and hypotheses
- theorem dependencies
- decisive inferences
- domain restrictions
- implication direction
- case coverage
- boundary conditions
- whether the conclusion fully matches the original claim

## External review

Mathematics teachers, olympiad coaches, professors, tutors, and experienced competition students are invited to review focused sections of the book.

Reviewers may:

- submit general feedback through GitHub Discussions
- report specific errors through GitHub Issues
- complete a structured external-review form
- permit an attributed review to be published in `REVIEWS.md`

Reviews should identify the chapters examined and provide honest criticism. Positive reviews are not expected or required.

## Reporting errors

Please open a GitHub Issue and include:

1. page number
2. chapter or section
3. quoted statement or proof step
4. explanation of the concern
5. suggested correction, if available

Confirmed corrections will be documented in `ERRATA.md`.
